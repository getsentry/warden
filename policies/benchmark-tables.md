# Benchmark Tables

## Intent

Keep benchmark comparisons focused on results and easy to scan.

## Policy

- Apply this policy to the benchmark overview, cost table, and any alternate
  layouts or future variants of those tables.
- Sort the score table by known-corpus recall, highest first.
- Keep the existing comparison metrics, model names, runtimes, and effort levels.
  Do not add metadata columns, badges, or labels unless the user explicitly asks.
  This includes production labels, chunk counts, dates, and configuration details.
- Keep detailed run metadata in the result files. Put necessary result caveats in
  the analysis or a concise note below the table.

## Exceptions

- Add metadata only when the user explicitly requests it.
